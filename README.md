# 🎀 나의 디지털 다꾸

일기, 독서 기록, 오늘의 사진 한 컷, 운동 기록을 **한 장의 다이어리 페이지**로 꾸며서 이미지로 저장하는 웹앱입니다.
2026년 K-컬쳐 디자인 흐름(조각보 컬러 블록, 한지 결, 낙관 도장, 포토카드·네컷 감성, 굵은 먹선 스티커)을 배경과 페이지에 담았습니다.

설치나 빌드 없이 `index.html`을 브라우저로 열면 바로 쓸 수 있습니다.

---

## 주요 기능

| 영역        | 할 수 있는 일                                                                                     |
| ----------- | ------------------------------------------------------------------------------------------------- |
| ✏️ 일기     | 제목, 기분(7종), 날씨(6종), 본문(최대 500자)                                                      |
| 📚 독서     | 책 제목, 지은이, 읽은 쪽수, 상태(읽는 중·완독·다시 읽기·잠시 멈춤), 별점, 마음에 남은 문장        |
| 💪 운동     | 운동 종류·시간·강도를 여러 개 추가, 총 운동 시간 자동 합산, 걸음 수                               |
| 📸 사진     | 사진 올리기(클릭 또는 끌어다 놓기), **필터 9종**, 필터 강도·밝기 조절, 프레임 4종, 프레임 문구    |
| 🎀 꾸미기   | 속지 테마 4종, 마스킹테이프 문구, 스티커(이모지 24종 · 문구 10종 · 모양 10종), 나만의 문구 스티커 |
| 🗂️ 모아보기 | 기록 종류별 필터, 월별 필터, 키워드 검색, 누적 통계                                               |
| ⬇️ 다운로드 | 꾸민 페이지를 1800×2400 PNG로 저장, 전체 기록 JSON 백업/불러오기                                  |

### 사진 필터

`원본` · `서울 필름` · `먹빛 흑백` · `레트로 90s` · `청량 여름` · `벚꽃 엔딩` · `K-비비드` · `몽글 파스텔` · `시티팝 나이트`

필터는 CSS `filter`가 아니라 픽셀을 직접 계산합니다. 그래서 화면에서 본 색 그대로 PNG에 저장되고, 사파리처럼 캔버스 필터를 지원하지 않는 브라우저에서도 똑같이 보입니다.

### 사진 프레임

| 프레임     | 특징                                      |
| ---------- | ----------------------------------------- |
| 폴라로이드 | 흰 여백 아래 손글씨 문구와 날짜           |
| 포토카드   | 홀로그램 테두리, 둥근 모서리, 문구 말풍선 |
| 필름       | 필름 구멍과 주황색 날짜 문구              |
| 한지 액자  | 한지 결, 매듭 장식, 다홍색 낙관 도장      |

### 스티커 다루기

- 스티커 칸을 누르면 페이지 가운데쯤에 붙습니다.
- **끌어서** 옮기고, 오른쪽 아래 **파란 손잡이**를 끌면 크기와 각도가 함께 바뀝니다.
- 선택한 스티커 위에서 **마우스 휠**로 크기를 바꿀 수 있습니다.
- 아래 도구 막대로 작게·크게·회전·맨 앞으로·복제·떼기를 할 수 있습니다.
- 키보드: `Delete`/`Backspace` 떼기, `Esc` 선택 해제.

## 실행 방법

### 1. 바로 열기

`index.html`을 더블클릭해서 브라우저로 엽니다. ES 모듈을 쓰지 않아서 `file://` 주소에서도 동작합니다.

### 2. 로컬 서버로 열기 (권장)

```bash
# Python
python3 -m http.server 5173

# 또는 Node.js
npx serve .
```

브라우저에서 `http://localhost:5173`을 엽니다.

### 3. 배포

정적 파일뿐이라 GitHub Pages, Netlify, Vercel 등에 폴더째 올리면 됩니다.

> 글꼴(Black Han Sans, Gowun Batang, Gowun Dodum, Gaegu)은 Google Fonts에서 불러옵니다. 인터넷이 없으면 시스템 글꼴로 대신 표시됩니다.

│   ├── stickers.js     # 스티커 목록, 그리기, 선택·충돌 판정

├── .editorconfig

스크립트는 `storage → filters → stickers → renderer → app` 순서로 불러오며, 모두 전역 `window.Dakku` 아래에 모듈을 붙입니다.

## 데이터 저장

- 모든 기록은 브라우저 **localStorage**의 `digital-dakku:v1` 키에 날짜별로 저장됩니다. 서버로 보내지 않습니다.
- 사진은 긴 변 1100px, JPEG 84% 품질로 줄여서 저장합니다.
- 브라우저 저장 공간은 보통 5MB 안팎이라 사진이 많이 쌓이면 가득 찰 수 있습니다. 상단에 `저장 공간 부족`이 보이면 **백업 → 백업 파일 다운로드**로 JSON을 받아 두고 오래된 날의 사진을 빼주세요.
- 다른 기기로 옮길 때는 백업 JSON을 받아서 **백업 파일 불러오기**로 합치면 됩니다. 같은 날짜는 백업 파일 내용으로 바뀝니다.

## 고쳐 쓰기

### 필터 추가 — `js/filters.js`

```js
{
  id: "matcha",
  label: "말차 라떼",
  fn(r, g, b) {
    const [sr, sg, sb] = saturate(r, g, b, 0.9);
    return [sr - 6, sg + 10, sb - 4];
  },
},
```

`PRESETS` 배열에 넣으면 사진 탭에 썸네일이 자동으로 생깁니다.

### 스티커 추가 — `js/stickers.js`

- 이모지: `EMOJI` 배열에 문자 추가
- 문구: `TEXTS` 배열에 `{ value, color }` 추가
- 모양: `SHAPES`에 `{ value, label, w, h }`를 넣고, `SHAPE_DRAW`에 같은 이름의 그리기 함수(중심 0,0 기준)를 추가

### 속지·프레임 추가 — `js/renderer.js`

`THEMES`와 `FRAMES` 객체에 `{ label, draw }`를 추가하면 꾸미기·사진 탭의 선택지에 자동으로 나타납니다.

### 운동 종류 추가 — `js/renderer.js`

`WORKOUT_ICON`에 `"이름": "이모지"`를 추가합니다.

### 코드 정렬

```bash
npx prettier --write .
```
